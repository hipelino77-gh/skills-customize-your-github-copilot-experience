# 📘 Assignment: Interactive Web Dashboard

## 🎯 Objective

Build an interactive directory of school clubs using HTML, CSS, and JavaScript. Practice displaying structured data in the browser and letting users search and filter it.

## 📝 Tasks

### 🛠️ Complete the club data and dashboard shell

#### Description
Open the provided starter file in a browser and inspect its club data and page controls. Add more clubs and make sure each entry has the information needed for a useful directory.

#### Requirements
Completed program should:

- Include at least 6 clubs in the JavaScript data array.
- Give each club a name, category, meeting day, and short description.
- Keep the search field, category selector, results count, and club list in the page.


### 🛠️ Display and filter clubs

#### Description
Use JavaScript to turn the club data into visible cards. Connect the search field and category selector so visitors can quickly find clubs.

#### Requirements
Completed program should:

- Display one card for every club that matches the current controls.
- Search club names and descriptions without requiring exact capitalization.
- Filter by category and allow the search and category filters to work together.
- Update the results count whenever the displayed clubs change.


### 🛠️ Polish and test the dashboard

#### Description
Style the directory so it is easy to scan on a phone or computer, then test both ordinary and edge-case searches.

#### Requirements
Completed program should:

- Arrange club cards in a readable layout that adapts to narrow screens.
- Show a clear message when no clubs match the current search and category.
- Show all clubs again when the search is cleared and the category is reset.
- Test at least one matching search, one category filter, and one search with no results.
